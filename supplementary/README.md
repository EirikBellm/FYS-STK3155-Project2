# Supplementary evidence

- `REPRODUCIBILITY.md` gives setup, data placement and commands for the ten submitted code files.
- `source/methods_reproducibility.tex` records numerical ordering, image transforms, random draws and scoring calls.
- `source/experiment_settings.tex` preserves the earlier extended settings excerpt for the saved experiments. Its historical source and runner references describe the earlier full project. Current commands are in `REPRODUCIBILITY.md`.
- `tables/matched_penalty_settings.csv` lists the sixteen matched penalty settings.
- `figures/penalty_search_inventory.pdf` shows the penalty-search inventory.
- `figures/classification_search.pdf` shows the classification-search inventory.
- `figures/activation_heatmaps.pdf` preserves the activation and learning-rate grid display.
- `records/` contains the supplementary tabular records. The full recovered experiment records, including weights, folds, curves and predictions, are under the root `results/` folder.
- `recovery_manifest.json` records each recovered file's original and submitted SHA-256 hashes.

These records were copied from the existing Project 2 folder on 6 November 2026. The execution guide and methods file were updated to match the submitted code. Numerical results were retained unchanged. Recovery did not refit models or rerun checks.
